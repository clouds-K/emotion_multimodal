# 🎭 Détecteur Multi-modal d'Émotions

Projet de fin de module - Intelligence Artificielle

## Description
Application de détection d'émotions combinant :
- 📸 Vision (expressions faciales)
- 🎤 Audio (ton de la voix)
- ✍️ Texte (analyse de sentiment)

## Installation
```bash
# Créer environnement virtuel
python -m venv venv --without-pip

# Activer
venv\Scripts\Activate.ps1

# Installer pip
python get-pip.py

# Installer dépendances
pip install -r requirements.txt
```
